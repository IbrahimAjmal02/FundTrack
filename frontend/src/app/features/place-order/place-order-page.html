How pricing works

Mutual funds are priced once a day, after market close. Every order placed today gets today's NAV: this is forward pricing.

  1. Order is placed → PENDING
  2. Operations enters today's NAV for each fund
  3. "Process day" prices every pending order
  4. → SETTLED or REJECTED (e.g. selling more units than held)
