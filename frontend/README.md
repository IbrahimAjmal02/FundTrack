# FundTrack frontend

Angular 22 app for FundTrack. See the [main README](../README.md) for what the project does and how to run it.

```bash
npm install
npm start        # http://localhost:4200, /api is proxied to the backend on localhost:8080
npm test         # unit tests (Vitest)
npm run build    # production build in dist/frontend/browser
```
